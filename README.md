# Sales Dashboard - Power BI Project

## Overview

This project presents an interactive Sales Dashboard developed using Power BI to analyze sales performance, revenue trends, customer behavior, and product performance. The dashboard helps stakeholders make data-driven business decisions through visual insights and key performance indicators (KPIs).

## Objectives

* Monitor overall sales performance.
* Track revenue and profit trends.
* Analyze sales by product category and region.
* Identify top-performing products and customers.
* Support business decision-making through interactive visualizations.

## Tools Used

* Power BI
* Microsoft Excel / CSV Dataset
* Power Query
* DAX (Data Analysis Expressions)

## Key Features

### Sales Performance Analysis

* Total Sales Overview
* Total Profit Analysis
* Total Orders Tracking
* Average Sales Calculation

### Regional Analysis

* Sales by Region
* Profit by Region
* Regional Performance Comparison

### Product Analysis

* Top Selling Products
* Product Category Performance
* Product-wise Revenue Contribution

### Time Series Analysis

* Monthly Sales Trend
* Quarterly Performance
* Year-over-Year Comparison

### Interactive Filters

* Region Filter
* Product Category Filter
* Date Range Filter
* Customer Segment Filter

## Key KPIs

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Average Order Value
* Top Performing Product
